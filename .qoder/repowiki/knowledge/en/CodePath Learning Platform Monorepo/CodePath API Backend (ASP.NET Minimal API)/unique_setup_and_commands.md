Run with `dotnet run --project src/Api/CodePath.Api` after loading `.env` (development) or Docker Compose via `docker-compose.yml`. Database migrations are applied through the app itself (`--migrate` flag) or a standalone `bin/migrator/CodePath.Migrator.exe` binary. Optional subsystems require explicit config keys: `Judge:Enabled` enables the judge worker and endpoints; `Ai:Enabled` additionally requires Judge and wires up SignalR plus the Python RAG client. Secrets can be mounted under `/run/secrets` as files where filenames map to config keys (`__` → `:`).
