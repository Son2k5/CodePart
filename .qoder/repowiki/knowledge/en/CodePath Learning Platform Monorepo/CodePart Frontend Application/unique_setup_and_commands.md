`npm run dev` starts Vite on port 5173 with HTTPS proxying to `https://localhost:5001` using TLS certs from `../api/secrets/dev/localhost.{pem,key}`; `npm run dev:workspace` runs Vite in `--mode workspace`; `npm run test:workspace` runs vitest against `vitest.config.ts`; `npm run test:workspace:e2e` runs Playwright against `playwright.workspace.config.ts`; Docker build produces a two-stage image (node:24-alpine builder → nginx:1.28-alpine runtime).
