Single-page React application bootstrapped via `src/main.tsx` with routes declared in `src/App.tsx` using `react-router-dom`'s `createBrowserRouter`. Feature boundaries are organized under `src/features/<feature>/` (admin, auth, teacher, home, workspace, code-judge, ai-assistant, landing, learning, classes, online-judge), each following a consistent sub-folder layout of `api/`, `components/`, `pages/`, `hooks/`, `store/`, `types/`, and `styles/`. Shared UI primitives live in `src/components/common/` and `src/lib/` (axios instance with token refresh, TanStack Query client, error service). Authentication state is centralized in a Zustand store (`features/auth/store/authStore.ts`) and enforced at the route level by `GuestRoute`, `ProtectedRoute`, and `RoleGuard`. HTTP calls go through a single Axios instance that intercepts requests to attach Bearer tokens, retries on 401 via `/auth/refresh-token`, and handles session idle/expired flows. Build-time chunking in `vite.config.ts` splits vendor bundles (react, react-router, react-query, monaco-editor, codemirror, lucide-react) into separate chunks. Development server proxies `/api`, `/health`, `/swagger` to `https://localhost:5001` using local TLS certs; mock mode (`VITE_USE_MOCK=true`) switches to port 5174 and uses MSW workers from `public/mockServiceWorker.js`. Production image is built with Node and served by Nginx via `nginx/default.conf`.
