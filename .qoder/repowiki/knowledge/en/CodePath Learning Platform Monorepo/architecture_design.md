Three sibling services are composed rather than linked by code: `api_backend` (ASP.NET Minimal API) owns the domain, persistence (EF Core → MySQL), caching (Redis), auth, and exercise/judge endpoints; `frontend_app` (React + Vite) is a thin client that proxies `/api`, `/health`, `/swagger` to the backend over HTTPS via Vite dev proxy; `ai_service` (FastAPI) runs as an optional sidecar behind the same API layer when `Ai__Enabled=true`/`Rag__Enabled=true`. Cross-service boundaries are HTTP-only — the backend calls the AI service using `SERVICE_API_KEY`, and the frontend never talks directly to it. Docker profiles (`ai`, `rag`) in `api/docker-compose.yml` gate the AI/Qdrant/indexer containers, while production uses a separate `docker-compose.production.yml` fronted by nginx. The root `package.json` only declares frontend-side editor/markdown deps consumed by the React app.
