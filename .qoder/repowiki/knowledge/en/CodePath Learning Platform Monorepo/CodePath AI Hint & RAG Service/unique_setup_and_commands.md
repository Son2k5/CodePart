Requires env vars `SERVICE_API_KEY` (≥32 chars, HMAC-verified via `X-Service-Key` header), optional `REDIS_URL`, optional `MODEL_PATH` or `MODEL_MANIFEST` (JSON pointing at a `.joblib` classifier). Development mode toggled by `ENVIRONMENT=development` enables `/docs`, `/redoc`, `/openapi.json`. Run with `uvicorn app.main:app` (or via Dockerfile). Tests use pytest with `asyncio_mode = auto`.
